# 🤖 AI Interview Preparation Platform (Backend)

Backend API for the AI Interview Preparation Platform built using Spring Boot.

## 🚀 Features

- JWT Authentication
- User Registration & Login
- AI Resume Analysis
- AI Mock Interview APIs
- Java & DSA Question APIs
- Progress Tracking
- MySQL Database Integration

## 🛠️ Tech Stack

- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- MySQL
- JWT
- OpenRouter API

## 📁 Project Structure

```
src/
├── controller/
├── service/
├── repository/
├── entity/
├── dto/
├── config/
└── security/
```

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/Vaishnavi174/AI_Interview_prep_backend.git
```

2. Configure your database in:

```
src/main/resources/application.yml
```

3. Build and run

```bash
mvn spring-boot:run
```

Backend runs at:

```
http://localhost:8080
```
